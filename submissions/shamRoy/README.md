### After

After completing these courses, I have a better understanding of how to use AI effectively as a development assistant. I learned the importance of providing clear context, relevant code, error messages, and expected behaviour to get more accurate and useful suggestions. I also learned to break down complex problems into smaller tasks, use AI to understand unfamiliar code, explore possible solutions, and approach debugging more systematically. When applying these techniques to my work on the Verteil Angular airline booking application, I can use AI to support code understanding, UI issue investigation, API debugging, and problem-solving. I also learned the importance of critically reviewing AI-generated suggestions, checking for potential side effects, and testing changes before considering a task complete.


### What I learned

* Better prompts: Providing relevant code, error messages, and expected behaviour helps AI generate more accurate and useful suggestions.
* Critical thinking: AI-generated solutions may not always fit the existing implementation, so reviewing the logic, considering potential side effects, and testing changes are essential.
* Task breakdown: Breaking complex problems into smaller steps makes it easier to investigate issues and evaluate possible solutions.
* Responsible AI use: AI can assist with development, but the developer remains responsible for validating the output and ensuring the final implementation works as expected.
