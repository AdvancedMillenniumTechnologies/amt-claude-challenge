# What I Learned - Claude Upskilling Challenge

## Track B

I completed the following Claude Academy courses:

- Claude 101
- AI Fluency: Framework & Foundations

## What I Learned

These courses helped me understand how to use AI more effectively as a development assistant.

I learned that Claude is not only useful for generating code. It can also help me understand existing code, investigate problems, explain unfamiliar concepts, and improve my approach to solving development tasks.

In my day-to-day work on the NRC application, I work on different types of tasks, including:

- UI issues and Angular components
- Backend/API issues
- Language translation and i18n issues
- Debugging existing functionality
- Understanding application structure and how different components and services are connected

Claude has helped me work through these tasks by explaining code, identifying possible causes of issues, suggesting solutions, and helping me understand unfamiliar parts of the application.

## Before

When I faced an issue in the application, I would usually investigate the code manually by looking through components, services, APIs, and related files.

For unfamiliar areas of the application, it could take time to understand how everything was connected before I could start fixing the issue.

For example, for a UI issue I might need to search through the component HTML, TypeScript, and CSS to understand where the problem was coming from. For backend issues, I might need to trace the API from the controller through the service and database logic.

## After

Now I use Claude as a development assistant during my investigation.

I provide Claude with the relevant code, error message, and expected behavior and ask it to help me understand the problem.

Instead of immediately asking for a solution, I can ask Claude to:

1. Explain what the existing code is doing.
2. Identify where the problem could be coming from.
3. Explain the possible solutions.
4. Suggest a minimal and scoped code change.
5. Help me verify whether the change could affect other parts of the application.

I still review and verify the suggestions before applying them.

## Real Development Examples

### UI Issues

Claude can help me understand Angular templates, components, CSS, and component relationships when investigating UI problems.

### Backend Issues

Claude can help me trace how data moves through controllers, services, APIs, and database queries and explain the existing implementation.

### Translation Issues

For language and translation issues, Claude can help identify translation keys, understand how the i18n structure works, and suggest appropriate changes.

### Understanding the NRC Application

One of the biggest benefits has been using Claude to understand the structure of the NRC application.

When working in an unfamiliar area, Claude can help explain how components, services, APIs, and other parts of the application are connected. This makes it easier for me to navigate the existing codebase and work on tasks more confidently.

## What Changed

Before using Claude more effectively, I mainly used AI when I needed an answer or a piece of code.

After completing these courses, I have a better understanding of how to work with AI as a collaborative assistant.

The biggest changes for me are:

- I can understand unfamiliar code faster.
- I can investigate issues more systematically.
- I can use Claude for both frontend and backend problems.
- I can use Claude for debugging and explanation, not just code generation.
- I think more carefully about the task before delegating it to AI.
- I verify AI suggestions instead of blindly accepting them.

The courses also reinforced that human judgment is still important. Claude can help with reasoning and implementation, but I am responsible for understanding the problem, checking the output, and deciding whether the suggested solution is appropriate.
